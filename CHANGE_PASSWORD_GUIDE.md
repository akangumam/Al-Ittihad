# 🔑 Cara Ganti Password - Quick Guide

## ✅ **2 Ways to Access Change Password:**

### **Option 1: Via User Menu (Recommended)** 👤

1. **Login** ke aplikasi
2. **Klik avatar/profile icon** di pojok kanan atas navbar
3. **Klik "Account Settings"** dari dropdown menu
4. **Klik tab "Security"** (jika ada tabs)
5. Isi form **Change Password**

---

### **Option 2: Direct URL** 🔗

```
http://localhost:3000/id/pages/account-settings
```

Atau untuk bahasa Inggris:

```
http://localhost:3000/en/pages/account-settings
```

---

## 📝 **Step-by-Step Instructions:**

### **1. Login with Default Credentials**

```
Email: admin@alittihad.sch.id
Password: password123
```

### **2. Navigate to Account Settings**

- **Klik avatar** (pojok kanan atas)
- **Pilih "Account Settings"**

### **3. Tab Security**

- Jika ada tabs, klik tab **"Security"**
- Jika tidak ada tabs, scroll ke section **"Change Password"**

### **4. Fill Change Password Form**

**Fields:**

- **Current Password**: `password123` (password default)
- **New Password**: Buat password baru yang kuat
  - Contoh: `AlIttihad@2026`
- **Confirm New Password**: Ketik ulang password baru

**Password Requirements:**

- ✅ Minimal **6 karakter**
- ✅ Gunakan kombinasi huruf besar & kecil (recommended)
- ✅ Tambahkan angka atau simbol (recommended)

### **5. Save Changes**

- Klik button **"Save Changes"**
- Tunggu notifikasi "Password berhasil diubah"

### **6. Test New Password**

- **Logout** dari aplikasi
- **Login kembali** dengan password baru
- Jika berhasil, password sudah berubah! ✅

## ⚠️ **Important Notes:**

1. **Change password immediately** setelah first login (security best practice)
2. **Save password** di password manager (Chrome, LastPass, 1Password, etc)
3. **Jangan share password** dengan orang lain
4. **Ganti password secara berkala** (setiap 3-6 bulan recommended)

## 🆘 **Troubleshooting:**

### **Problem: "Current password is incorrect"**

**Solution:**

- Check CAPS LOCK tidak aktif
- Pastikan ketik `password123` dengan benar (lowercase semua)
- Atau gunakan password yang sudah pernah di-update

### **Problem: "New password and confirm password do not match"**

**Solution:**

- Ketik ulang dengan teliti
- Pastikan tidak ada spasi di awal/akhir
- Copy-paste dari notepad untuk ensure consistency

### **Problem: "Tidak menemukan menu Account Settings"**

**Solution:**

- **Refresh page** dengan Ctrl + F5
- **Clear browser cache** and reload
- **Check code changes** sudah di-apply (hot reload Next.js)
- Atau akses langsung via URL: `/pages/account-settings`
