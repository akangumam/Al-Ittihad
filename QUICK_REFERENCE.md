# 📌 Quick Reference - Urutan Setup Sistem

**Simpan atau print halaman ini sebagai panduan cepat!**

---

## ⚡ Urutan Setup (WAJIB IKUTI!)

### **TAHAP 1: Master Data** (Lakukan SEKALI di awal)

```
1. Setup Tahun Ajaran           → Menu: Akademik → Tahun Ajaran
   ✅ Buat tahun ajaran aktif

2. Setup Data Kelas             → Menu: Akademik → Data Kelas
   ✅ Buat kelas 7A, 7B, 7C, 8A, 8B, dst

3. Setup Akun Kas & Bank        → Menu: Pengaturan → Manajemen Kas/Bank
   ✅ Kas Tunai + Bank BRI (minimal)
   ✅ Input saldo awal

4. Setup Kategori Transaksi     → Menu: Pengaturan → Kategori Transaksi
   ✅ Kategori Pemasukan: Pembayaran Siswa, Dana BOS, Donasi
   ✅ Kategori Pengeluaran: Operasional, Gaji, Pemeliharaan
```

---

### **TAHAP 2: Data Operasional**

```
5. Input Data Guru              → Menu: Akademik → Data Guru
   ✅ Input minimal 5 guru

6. Input Data Siswa             → Menu: Akademik → Data Siswa
   ✅ NIS, NISN, Nama, Kelas, No HP Ortu (WAJIB!)

7. Assign Wali Kelas            → Menu: Akademik → Data Kelas
   ✅ Edit kelas → pilih wali kelas
```

---

### **TAHAP 3: Setup Tagihan**

```
8. Buat Template Biaya          → Menu: Biaya Sekolah → Template Biaya
   ✅ Template: Daftar Ulang, Seragam, Kegiatan

9. Assign Tagihan ke Siswa      → Menu: Biaya Sekolah → Penetapan Tagihan
   ✅ Manual per siswa ATAU massal per kelas
```

---

### **TAHAP 4: Transaksi Harian** (Rutin setiap hari)

```
10. Input Pembayaran Siswa       → Menu: Biaya Sekolah → Pembayaran Siswa
    ✅ Pilih siswa → pilih tagihan → input nominal → simpan

11. Catat Pemasukan Lain         → Menu: Kas & Bank → Pemasukan Kas
    ✅ Dana BOS, Donasi, dll

12. Catat Pengeluaran            → Menu: Kas & Bank → Pengeluaran Kas
    ✅ ATK, Listrik, Gaji, dll

13. Mutasi Antar Kas             → Menu: Kas & Bank → Mutasi Antar Kas
    ✅ Transfer kas ke bank / sebaliknya
```

---

## 🔥 Field WAJIB Saat Input Data

### **Input Siswa:**

- ✅ NIS (unique)
- ✅ NISN (unique)
- ✅ Nama Lengkap
- ✅ Jenis Kelamin
- ✅ Tingkat/Kelas
- ✅ **Kelas** (harus pilih, tidak boleh kosong!)
- ✅ No. HP Orang Tua/Wali

### **Input Transaksi:**

- ✅ Tanggal
- ✅ Kategori
- ✅ Nominal
- ✅ Akun Kas/Bank
- ✅ Keterangan

---

## ⚠️ JANGAN SAMPAI LUPA!

### **✅ DO's:**

1. ✅ Setup tahun ajaran AKTIF dulu sebelum input kelas
2. ✅ Setup kelas dulu sebelum input siswa
3. ✅ Setup akun kas/bank dulu sebelum input transaksi
4. ✅ Setup template biaya dulu sebelum assign tagihan
5. ✅ Backup data minimal 1x seminggu

### **❌ DON'Ts:**

1. ❌ JANGAN skip setup master data
2. ❌ JANGAN input siswa tanpa pilih kelas
3. ❌ JANGAN lupa input saldo awal kas/bank
4. ❌ JANGAN hapus data yang sudah ada transaksi
5. ❌ JANGAN ada 2+ tahun ajaran aktif bersamaan

| ---------------------- | ---------------------------------- |

| Saldo tidak update     | Refresh halaman (F5)               |
